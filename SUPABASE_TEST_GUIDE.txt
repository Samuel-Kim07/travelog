Travelog Supabase 연결 테스트 가이드
=================================

이번 버전은 Supabase를 원본 서버로 쓰고, 구매한 가이드는 오프라인 패키지로 디바이스 IndexedDB에 내려받아 GPS만으로 실행하는 기초 구조를 포함합니다.

- Public bucket: guide-public
- Private bucket: guide-media

테스트 순서
1. GitHub Pages에 이 압축 파일 내용을 업로드합니다.
2. 앱을 실행합니다.
3. 처음 로그인 단계에서 게스트 또는 이메일을 선택합니다.
   - 게스트: Supabase Anonymous Auth가 켜져 있어야 서버 출간/구매/다운로드가 됩니다.
   - 이메일: 이메일과 비밀번호 프롬프트가 뜹니다. 기존 계정이면 로그인, 새 계정이면 가입을 시도합니다.
4. 프로필과 저장소 설정을 완료합니다.
5. 스튜디오에서 핀/음성/영상/사진/텍스트 메모를 생성합니다.
6. 저장하기를 먼저 누릅니다.
7. 최종 출간하기를 누르면 Supabase Database/Storage로 전송됩니다.
8. 홈 화면에서 Supabase 가이드가 오늘의 가이드 목록에 표시되는지 확인합니다.
9. 다른 브라우저/다른 기기에서 같은 GitHub Pages 주소를 열고 해당 가이드를 구매합니다.
10. 내 가이드 보관함에서 “다운로드 후 시작”을 누르면 guide-media 파일이 IndexedDB에 저장됩니다.
11. 다운로드 완료 후에는 인터넷 없이 가이드 시작이 가능해야 합니다. 단, 지도 배경 타일은 별도 오프라인 캐시가 없으면 보이지 않을 수 있고 GPS/핀/메모 실행은 로컬 패키지를 사용합니다.

주의
- service_role key, DB password, JWT secret은 절대 앱 코드에 넣지 마세요.
- Supabase Anonymous Auth가 꺼져 있으면 게스트 상태에서 출간/구매/다운로드가 막힐 수 있습니다. 이 경우 이메일 로그인을 사용하거나 Supabase에서 Anonymous Sign-Ins를 켜야 합니다.
- 코인 차감은 이번 버전에서 아직 클라이언트/테스트용입니다. 실제 운영 전에는 Supabase Edge Function 또는 DB RPC로 서버 처리해야 합니다.
